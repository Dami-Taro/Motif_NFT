# Motif_Nft

## Descrizione
Motif_Nft è un progetto sviluppato in Java/Python (specificare meglio se necessario) che implementa funzionalità legate alla gestione e/o elaborazione di NFT.

## Requisiti
- Java JDK (versione 8 o superiore consigliata)
- Python (se utilizzato nel progetto)
- Sistema operativo compatibile (Linux/macOS consigliati per i comandi sotto)


## Come eseguire il progetto

### 1. Entrare nella directory del progetto
```bash
cd my_java
```

### 2. Compilazione del progetto
```bash
javac -cp "lib/*" -d bin $(find src/ -name "*.java")
```


### 3. Esecuzione Motif Mining
```bash
java -cp "bin:lib/*" src.main.Main
```


### 3. Esecuzione Overleaf Creator
```bash
java -cp "bin:lib/*" src.results.GenerateOverleaf
```
